# v1.0.0 – Arbeitsstand und Fortsetzung

Branch: `release/v1.0.0`, Ausgangspunkt `2abefde` (main mit PR #8). Keine Veröffentlichung, kein Merge, kein Tag.

## Bestandsaufnahme abgeschlossen

- Website: statisches HTML/CSS/Vanilla JS, Katalog und Release-Erkennung bleiben erhalten.
- Python 3.12, Node 24, Java 21; Compiler aktivieren mit `export PATH=/workspace/.local/bin:$PATH`.
- Pack unverändert Minecraft 26.3 / Fabric 0.19.5; Spiel benötigt Java 25.
- Offizielle Packwiz-Werkzeuge unter `build/customization/`, SHA-256 geprüft.
- Alle 108 Server-JARs aus dem bestehenden v0.0.2-Serverrelease unter `build/release-source/mods/` gegen die aktuellen Packwiz-Hashes geprüft. Keine Modupdates nötig.
- Prism-UI-Bezeichnungen an offiziellem Source-Tag 11.1.1, Commit `7d2d3c1ec6fcf8255ebacd02d9f792688575dfb4`, geprüft. Keine laufende Prism-GUI; Illustrationen werden ausdrücklich schematisch.
- Zoomify 2.17.0: Source-Commit `4abaf61b97e9615b98de57c5171393b8f8ef5bb0`; C / F6 belegt. Weitere Steuerungen werden nur mit Beleg beziehungsweise als nicht verifiziert aufgenommen.
- Browser-Altfehler: Warten auf lazy Icons unterhalb des Viewports; im Releaseauftrag darf der Test korrekt repariert werden.
- GitHub-Gitproxy: Lesen funktioniert. `gh api` wird mit Forbidden blockiert. Keine Tokenwerte auslesen/anfordern. Push und Webzugriff später getrennt prüfen.

## Grenzen

Kein Minecraft-GUI-, Multiplayer- oder Dedicated-Server-Laufzeittest. Kein Anspruch auf eine vollständige Mod-Tastenliste. GitHub-API und externe Mod-CDNs sind in der aktuellen Netzwerkregel gesperrt. Bestehende Installationen müssen **vor** dem Merge/Pages-Update migriert werden; der Builder verweist weiterhin auf den öffentlichen main-Pages-Endpunkt.
