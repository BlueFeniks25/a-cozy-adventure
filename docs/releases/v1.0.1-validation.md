# v1.0.1 – Prüfbericht und Blocker

Stand: 19.10.2026. Ausgangspunkt ist main `6b34d2dad881decf1feac5643e3c7dca25f2b901`. Nur Release-Branch, keine produktiven Änderungen.

## Nachweise und Grenzen

- Packwiz: komplette Index-/Metadatenhashkette durch `build_serverpack.load_plan` geprüft; ColorLight-Mod und Standard-Config fehlen. 136 Mods: 108 `both`, 28 `client`. 105 ausgewählte Serverconfigs bleiben unverändert, ein ungenutzter Client-Config wurde entfernt.
- Abhängigkeiten: 136 unveränderte JAR-Identitäten gegen den vorherigen Audit abgeglichen, 306 gespeicherte Fabric-Metadatensätze neu ausgewertet; 24 unabhängige Clientoptionen und vier erforderliche Clientbibliotheken. Kein verbleibender Pflichtnutzer von ColorLight. Dies ist keine neue vollständige Original-JAR-Prüfung und kein Fabric-Laufzeittest. Reproduktion: `git show 6b34d2d:docs/customization/dependencies.json > previous.json`, dann `python -B scripts/audit_customization.py --snapshot previous.json`. Der Snapshotmodus lehnt unbekannte/geänderte Pins ab; Unified erfordert eine neue echte JAR-Prüfung.
- Offizielles v1.0.0-Protector-Asset 656125771 über GitHub geladen und gegen den von der Release-API gelieferten SHA-256 `99dc680b056805515d48cab3800a096239b4206ee584402873107fe06023ffc6` geprüft. Der Prism-Builder verwendet dieselben Bytes für Import und Migration.
- Regressionen: aktiv/deaktiviert → offiziell entfernt → Besitz freigegeben → dieselben Bytes privat neu installiert → weitere Updates; unklare veränderte Dateien und Doppelbestand müssen ohne Zustandsänderung anhalten. Zusätzlich echte veröffentlichte v1.0.0-JAR → hashgesichertes Protector-Upgrade → Packversion 1.0.1 ohne Neuinstallation/Reset; private Mods, Maps und Einstellungen bleiben erhalten.
- Vorhandene Browserprüfungen wurden ausgeführt: Katalog, Spielerwege, Projektpfad, sechs Breiten und 29 Release-Erkennungsszenarien. Der abschließende Lauf nach den letzten Änderungen ist bei diesem Zwischencommit noch offen.
- Abschließende vollständige Python-/Packwiz-Suite einschließlich neuer Regressionen läuft noch. Ein früherer Lauf deckte eine alte hartcodierte Modzahl auf; sie ist durch den Vergleich mit dem Audit ersetzt. Ergebnisse werden vor Abschluss ergänzt.
- Python-Werkzeuge unverändert mit Python 3.11+-Schnittstelle; lokale Java-Builds mit vorhandenem JDK 21 und Java-17-Ziel. Spielstart erfordert Java 25; Minecraft wurde nicht gestartet. Unter Linux bleibt die bestehende Windows-8.3-Prüfung plattformspezifisch offen; CI prüft Windows/Linux und Java 17/25.

## Build- und Integrationsblocker

CurseForge ist nach Zugriff über den konfigurierten Cloud-Proxy mit `HTTP/1.1 403 Forbidden` gesperrt. Die passende Unified-2.0.4-Fabric-26.3-Datei samt Hash und Abhängigkeiten kann nicht sicher verifiziert werden. Kein Modfile, Hash, Projekt-/Datei-ID oder Persistenzpfad wurde geraten. GitHub-Zugriff funktioniert außerhalb der lokalen Loopback-/Netzwerksandbox.

`python -B scripts/prepare_release.py` hält vor Downloads mit `v1.0.1 blocked: verified Unified Xaero Worldmap Fabric 26.3 metadata/JAR missing` an. Daher keine vollständigen Prism-/Server-Releasekandidaten und keine zugehörigen Release-Prüfsummen. Die Kandidaten-CI soll diesen unvollständigen Stand ebenfalls ablehnen; ihr Prüfbericht kann als Artefakt verfügbar sein. Isolierte Schutz-CI-Artefakte sind kein vollständiges v1.0.1-Releasepaket.
