# Java und Prism-Migration

Das Schutz- und Migrationsprogramm benötigt **Java 17 oder neuer**. Seine Klassen werden mit dem Java-17-Ziel kompiliert; die CI prüft Java 17 und 25 auf Windows und Linux. **Minecraft 26.3 benötigt für dieses Modpack weiterhin Java 25.** In Prism muss deshalb Java 25 für den Spielstart ausgewählt bleiben. Das mitgelieferte Schutzprogramm verwendet beim automatischen Start dieselbe Java-Installation wie Prism.

Eine neue Prism-ZIP enthält einen kleinen Startwert für `minecraft/options.txt`: Vanilla und die vier offiziellen Ressourcenpakete in derselben relativen Reihenfolge wie v0.0.2 (Colorful Trims, Fresh Animations, FA Player, FA All Extensions). Weitere Tasten-, Grafik- oder Shader-Vorgaben werden nicht vorgegeben. Die Datei gehört danach dem Spieler. Sie wird weder im Packwiz-Index verwaltet noch bei einer Migration kopiert oder ersetzt.

Die einmalige Migration einer bestehenden Instanz prüft zuerst den bisherigen Pre-Launch-Befehl und mögliche Dateikollisionen. Sie legt eine vollständige Sicherung `instance.cfg.before-customization` an, kopiert danach das Schutz-JAR und schreibt **zuletzt** die neue `instance.cfg`. Die Sicherung wird aus einer fertig geschriebenen temporären Datei umbenannt und überschreibt keine vorhandene Sicherung. Das neue JAR und die Konfiguration werden jeweils über einen Austausch derselben Dateisystempartition geschrieben.

Ein Abbruch vor dem letzten Konfigurationsschritt lässt den bisherigen Startbefehl bestehen. Ein erneuter Migrationslauf akzeptiert bereits vollständig kopierte, identische Dateien und setzt die Migration fort. Nach einem erfolgreichen Lauf verändert ein identischer Wiederholungsaufruf keine Dateien. Unbekannte Startbefehle, abweichende vorhandene JARs oder Sicherungen sowie symbolische Verknüpfungen führen zum sicheren Abbruch. Persönliche Mods, Ressourcenpakete, Shader, Welten und Einstellungen werden von der Migration nicht verändert. Bei Dateisystemfehlern bleibt der vorherige Startbefehl beziehungsweise die vorhandene Sicherung die Grundlage für eine sichere Wiederherstellung; eine unbekannte Konfliktdatei wird niemals automatisch entfernt.
