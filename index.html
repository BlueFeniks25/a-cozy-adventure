01 · JETZT SPIELEN

Dein erster Abend in unserer Welt.

Prism Launcher hält dieses Modpack in einer eigenen Instanz: einem getrennten Spielordner mit passenden Mods und Einstellungen. Du brauchst Minecraft: Java Edition auf deinem eigenen Microsoft-Konto.

Minecraft 26.3Fabric 0.19.5Spielstart: Java 25
  1. Prism einrichten
  2. Prism-ZIP importieren
  3. Instanz starten
Ein Zuhause wartet schon auf dich.

Installations-ZIPs und Versionshinweise findest du auf GitHub.

GitHub Releases ansehen ↗

Der Download zeigt immer die neueste bereits veröffentlichte passende Version. Die Vorbereitung von v1.0.0 ist noch keine Veröffentlichung. Prüfe den Versionsnamen vor dem Import.

1. Prism installieren und dein Konto anmelden
  1. Lade Prism ausschließlich von prismlauncher.org/download für dein Betriebssystem herunter und installiere es.
  2. Starte Prism und schließe die Ersteinrichtung ab. Über Konten / Accounts → Konten verwalten / Manage Accounts beziehungsweise Einstellungen / Settings → Konten / Accounts kommst du zur Kontoliste.
  3. Wähle Microsoft hinzufügen / Add Microsoft. Folge der Anmeldung im Browser auf der echten Microsoft-Seite. Dein Konto muss Minecraft: Java Edition besitzen. Passwörter gehören weder in diese Website noch in einen Chat.
  4. Wähle dein hinzugefügtes Konto als aktives Konto aus. Die kostenlose Prism-App ersetzt keine Minecraft-Lizenz.
2. Die richtige ZIP herunterladen und importieren
  1. Nutze die Download-Schaltfläche oben. Auf GitHub benötigst du unter Assets die Datei A-Cozy-Adventure-Prism-v1.0.0.zip, sobald v1.0.0 veröffentlicht ist. Bis dahin zeigt der Link den bisherigen Release. Wähle weder die Server-ZIP noch „Source code“.
  2. Lass die ZIP ungeöffnet und unentpackt im Downloadordner.
  3. Klicke in Prism auf Instanz hinzufügen / Add Instance und wähle Importieren / Import. Über Durchsuchen / Browse wählst du die heruntergeladene ZIP.
  4. Bestätige den Import mit OK. Eine neue Kachel „A Cozy Adventure“ erscheint. Importiere in eine neue Instanz; überschreibe keine bestehende Welt.
3. Java prüfen, erstmals starten und Updates verstehen
  1. Wähle die Instanz und öffne Bearbeiten / Edit → Version. Minecraft 26.3 und Fabric Loader 0.19.5 gehören zu diesem Pack. Stelle sie nicht auf eigene Faust um.
  2. Prism kann eine passende Java-Laufzeit automatisch auswählen beziehungsweise herunterladen. Für das Spiel ist Java 25 erforderlich. Bei einem Java-Fehler prüfe Bearbeiten → Einstellungen → Java (Edit → Settings → Java), die automatische Auswahl oder eine vorhandene Java-25-Installation. Ein Java 17/21 für Hilfsprogramme genügt nicht für den Spielstart.
  3. Doppelklicke auf die Instanz oder wähle Starten / Launch. Beim ersten Start werden die offiziellen Mods geladen; das kann dauern. Bei vom Anbieter gesperrten Downloads befolge die konkreten Hinweise des Installers.
  4. Das Schutzfenster sagt „Persönliche Mods und Einstellungen werden geschützt“. Über Auswahl ändern kannst du optionale Bestandteile wählen. Ohne Eingriff läuft der Start nach vier Sekunden weiter.
  5. Vor späteren Starts prüft der Updater die offizielle Packdefinition. Er aktualisiert offiziellen Bestand; eigene Mods, Ressourcenpaket-Reihenfolge und persönliche Einstellungen bleiben geschützt. Bei Konflikten hält er an und nennt den betroffenen Pfad. Währenddessen keine Instanzdateien bearbeiten.

Nach dem ersten Start verwaltest du dieselbe Instanz weiter – kein erneuter ZIP-Import für jedes reguläre Modpack-Update. Aktualisiere offizielle Mods nicht einzeln über Prism; ihre Versionen werden vom Pack festgelegt.

Du hast bereits v0.0.2? Der alte Startbefehl aktiviert den Schutz nicht selbst. Lies zuerst die einmalige Migration deiner vorhandenen Instanz.

UI-Begriffe geprüft am offiziellen Prism-Quellstand 11.1.1; deutsche Übersetzungen können abweichen. Deshalb stehen die englischen Bezeichnungen dabei. Offizielle ZIP-Import-Hilfe.

02 · DEINE CLIENT-MODS

So, wie du gerne spielst.

Schließe Minecraft, wähle deine Instanz und öffne Bearbeiten / Edit → Mods. Die Schutzschicht behält persönliche Entscheidungen über spätere Updates bei.

Offizielle optionale Mods deaktivieren und wieder aktivieren
  1. Prüfe, ob die Mod optional ist: Das Schutzfenster beim Start zeigt über Auswahl ändern die offiziellen Optionen. Die geprüfte Optionsliste nennt die 25 optionalen Client-Mods. Der Katalog allein ist keine Freigabe zum Deaktivieren.
  2. In Bearbeiten → Mods entfernst du das Häkchen einer optionalen Mod, zum Beispiel ColorLight. Prism deaktiviert die Datei, statt sie zu löschen. Der geschützte Updater erhält diesen Zustand.
  3. Für die Rückkehr setzt du das Häkchen bei derselben Datei wieder. Alternativ aktivierst du sie in der Startauswahl. Beim nächsten Start wird nötigenfalls die aktuelle offizielle Version bereitgestellt.

Du hast versehentlich eine optionale Mod ausgeschaltet? Aktiviere sie genau so wieder. Pflichtmods und notwendige Bibliotheken bleiben aktiv. Sodium, libIPN und andere gemeinsam benötigte Bibliotheken sind keine beliebigen Schalter.

Prisms Modliste mischt eigene und offizielle Dateien. Vergleiche Namen und Dateiversion mit dem Pack-Katalog und der Optionsliste. Die Startauswahl enthält nur offizielle optionale Bestandteile. Offizielle Dateien nicht manuell löschen, wenn du sie nur ausschalten möchtest.

Eigene Client-Mods über Prisms Suche hinzufügen
  1. Öffne Bearbeiten / Edit → Mods → Mods herunterladen / Download Mods.
  2. Wähle Modrinth oder CurseForge, soweit in deiner Prism-Version und für die Mod verfügbar. Suche nach dem Namen.
  3. Kontrolliere vor dem Download Minecraft 26.3 und Fabric. Eine NeoForge-/Forge-Datei oder eine andere Minecraft-Version passt nicht automatisch. Prüfe die Projektseite auf benötigte Bibliotheken und Konflikte.
  4. Wähle die passende Datei, lade sie über den Dialog herunter und schließe die Bearbeitung ab. Prüfe angebotene Abhängigkeiten; eine Suche allein garantiert keine vollständige oder kompatible Auswahl.
  5. Starte und teste die Instanz. Persönliche Zusatzmods sind erlaubt, aber ihre Kompatibilität wird nicht pauschal garantiert.
Eine JAR manuell hinzufügen oder eine eigene Mod entfernen

Alternativ lade die passende JAR von der offiziellen Mod-Projektseite herunter und wähle in Prism Mods → Hinzufügen / Add. Du kannst sie auch über den Instanz-Spielordner in mods ablegen. Benötigte Bibliotheken ebenfalls prüfen. Manche CurseForge-Dateien lassen sich nur manuell beim Anbieter beziehen; solche Beschränkungen werden nicht umgangen.

Zum Entfernen einer selbst installierten Mod: Minecraft schließen, die Mod in Prism auswählen und Entfernen / Remove benutzen. Bewahre vorher eine Kopie auf, wenn du zurückwechseln möchtest. Für einen Test genügt das Deaktivieren.

Der Updater entfernt persönliche Dateien nicht ungefragt. Ein Namenskonflikt mit einer offiziellen Datei führt zu einem Stopp, auch bei gleichem Inhalt ohne Eigentumsnachweis. Sichere die persönliche Datei außerhalb von mods und kläre den Konflikt. Niemals .cozy oder packwiz.json zum Umgehen einer Meldung löschen.

03 · TEXTUREN & ANIMATIONEN

Deiner Welt einen eigenen Look geben.

Prism legt die Paketdateien bereit. Welche davon aktiv sind und was Vorrang hat, entscheidest du in Minecraft.

Ressourcenpakete hinzufügen und im Spiel aktivieren
  1. In Prism: Bearbeiten / Edit → Ressourcenpakete / Resource Packs. Pakete herunterladen / Download Packs öffnet die verfügbaren Anbieter. Oder wähle Hinzufügen / Add für deine eigene Ressourcenpaket-ZIP.
  2. Manuell geht es auch: Lege die unveränderte ZIP in den Ordner resourcepacks der Instanz. Prüfe die unterstützte Minecraft-Version und Hinweise des Erstellers.
  3. Starte Minecraft und öffne Optionen → Ressourcenpakete (Options → Resource Packs). Schiebe das Paket in die ausgewählte Liste. Zum Deaktivieren nimmst du es aus dieser Liste heraus. Bestätige mit Fertig / Done.
  4. Benutze die Pfeile am Paket, um es innerhalb der ausgewählten Liste nach oben oder unten zu verschieben. Ein weiter oben angezeigtes Paket hat bei denselben Dateien Vorrang.

UNTEN · BASIS

Dies ist die Startvorgabe für eine neue Prism-Instanz. Der Builder speichert sie in options.txt intern von niedriger zu höherer Priorität; oben siehst du die umgekehrte, sichtbare Minecraft-Reihenfolge. Bestehende persönliche Auswahlen und Reihenfolgen werden bei Updates nicht umsortiert.

Erweiterungen, eigene Pakete und Überschreibungen verstehen

Fresh Animations ist die Basis für die beiden Fresh-Animations-Erweiterungen. Die Erweiterungen gehören darüber. Die bereitgestellten Entity Model Features (EMF) und Entity Texture Features (ETF) ermöglichen die betreffenden Modelle und Texturen; lasse sie für diese Darstellung aktiviert. Die visuelle Funktion der gesamten Kombination muss dennoch im Spiel geprüft werden.

Colorful Trims RP ergänzt die Darstellung der zugehörigen Colorful-Trims-Mod. Lass die bisherige relative Reihenfolge der vier offiziellen Pakete zunächst stehen.

Ein zusätzliches Paket setzt du über die offiziellen Pakete, wenn seine enthaltenen Texturen gewinnen sollen; darunter, wenn es nur Lücken füllen soll. Pakete überschreiben nur die jeweils gleichen Ressourcen. Ein allgemeines Texturpaket oberhalb einer Animationserweiterung kann daher deren Wirkung verändern. Befolge zusätzlich die Kombinationshinweise des jeweiligen Erstellers.

Sieht etwas falsch aus? Prüfe Version, aktive Pakete, Reihenfolge und benötigte Mods. Deaktiviere Zusatzpakete probeweise. Eine rote Inkompatibilitätswarnung ist kein Kompatibilitätsnachweis.

Im Schutzfenster steuerst du, ob offizielle Paketdateien installiert bleiben. Das normale Aktivieren und Sortieren erfolgt im Minecraft-Menü. Eine manuell gelöschte offizielle ZIP wird erneut geladen, solange ihre Startoption an ist. Persönliche ZIPs werden nicht ungefragt entfernt.

Eigene Tasten ändern, Konflikte lösen und zurücksetzen
  1. Im Spiel: Optionen → Steuerung → Tastenbelegung (Options → Controls → Key Binds). Suche dort nach der Funktion oder scrolle zur Mod-Kategorie. Studious Keybinds unterstützt die Übersicht; die Bedienung kann von Vanilla abweichen.
  2. Klicke auf die aktuelle Belegung und drücke die gewünschte Taste. Prüfe die angezeigte neue Zuordnung.
  3. Bei einer als doppelt markierten Belegung ändere eine der betroffenen Funktionen auf eine andere Taste. Teste danach beide Funktionen im Spiel. Eine doppelte Taste ist nicht immer ein Konflikt, wenn Funktionen in unterschiedlichen Situationen wirken.
  4. Über Zurücksetzen / Reset an einer Funktion holst du deren Standard zurück. Alle zurücksetzen / Reset All betrifft sämtliche Belegungen und verwirft deine eigene Auswahl. Benutze das nur bewusst.

Persönliche Tasten in options.txt und vorhandene mod-spezifische Konfigurationen bleiben bei regulären geschützten Updates erhalten. Sichere deine Instanz vor größeren Anpassungen. Die Mod selbst kann beim Spielstart Einstellungen ändern; der Updater überschreibt sie nicht.

05 · HILFE & FAQ

Damit es gemütlich bleibt.

Muss ich Prism Launcher verwenden?

Unser geprüfter Import und der geschützte Startbefehl sind für Prism vorbereitet. Andere Launcher sind nicht Teil dieses getesteten Wegs. Für einen unkomplizierten Einstieg verwende Prism.

Muss ich Mods manuell aktualisieren?

Offizielle Mods werden vor dem Spielstart vom Pack-Updater verwaltet. Aktualisiere sie nicht einzeln. Nur deine selbst hinzugefügten Mods verwaltest du selbst; achte dabei auf Minecraft 26.3 und Fabric.

Darf ich eigene Client-Mods installieren?

Ja. Nutze Prisms Modsuche oder den JAR-Import. Der geschützte Updater bewahrt persönliche Dateien. Das garantiert weder Kompatibilität noch die Zulässigkeit jeder Zusatzfunktion auf einem Multiplayer-Server.

Wie deaktiviere ich ColorLight?

Minecraft schließen → Prism-Instanz bearbeiten → Mods → Häkchen bei ColorLight entfernen. Oder im Schutzfenster „Auswahl ändern“ verwenden. Nur optionale Bestandteile deaktivieren.

Warum bleibt eine deaktivierte Mod deaktiviert?

Die Schutzschicht merkt sich deine Auswahl und erkennt Prisms deaktivierte Datei. Zum Wiedereinschalten das Häkchen bei derselben Mod setzen oder die Startauswahl verwenden. Eine neue offizielle Version wird dann bei Bedarf installiert.

Wie ändere ich meine Tastenbelegung?

Im Spiel unter Optionen → Steuerung → Tastenbelegung. Unsere Tastenübersicht mit Anleitung hilft beim Finden; deine persönlichen Werte werden nicht von dieser Website ausgelesen.

Was passiert mit meinen Einstellungen nach einem Update?

Der geschützte Updater überschreibt options.txt nicht. Vorhandene mod-spezifische Konfigurationen bleiben erhalten; neue Vorgaben werden nur erstmals angelegt. Dies gilt für geschützte Instanzen – alte v0.0.2-Instanzen benötigen zuerst die Migration.

Warum funktioniert mein Ressourcenpaket nicht wie erwartet?

Prüfe, ob es im Spiel aktiviert ist, zur Minecraft-Version passt und seine benötigten Mods aktiv sind. Oben liegende Pakete überschreiben passende Ressourcen weiter unten. Siehe Reihenfolge und Erweiterungen.

Was mache ich, wenn Minecraft nach einer zusätzlichen Mod abstürzt?

Spiel schließen und eine Sicherung anlegen. Deaktiviere zunächst die zuletzt hinzugefügte persönliche Mod, starte erneut und prüfe ihre Abhängigkeiten und Version. Pflichtmods beibehalten. Bei Bedarf Prism-Konsole, logs/latest.log oder Crashreport mit der Packbetreuung prüfen; vor dem Weitergeben persönliche Angaben entfernen.

Wie migriere ich eine vorhandene v0.0.2-Installation?

Nicht einfach eine neue ZIP über die alte Instanz kopieren. Die einmalige Migration stellt den alten Startbefehl auf den geschützten Updater um. Neuinstallationen aus der neuen Prism-ZIP brauchen diesen Schritt nicht.

Schon v0.0.2 gespielt? Deine Instanz bleibt.

Eine neue Prism-ZIP ist für neue Instanzen. Für deine bestehende Testinstallation benötigst du die zur geprüften Version gehörende A-Cozy-Adventure-Prism-v1.0.0.migration.jar. Sie steht erst mit den freigegebenen Artefakten beziehungsweise dem späteren Release zur Verfügung – hier gibt es noch keinen v1.0.0-Live-Download.

  1. Minecraft schließen, Instanz nicht parallel starten und den gesamten Instanzordner sichern.
  2. Die geprüfte Migrations-JAR mit Java öffnen (mindestens Java 17, Java 25 funktioniert ebenfalls). Wenn der Doppelklick keine Java-Anwendung startet, die Datei über „Öffnen mit“ einer vorhandenen Java-Laufzeit zuordnen. Keine Entwicklerbefehle nötig.
  3. Den Instanzordner wählen, der instance.cfg, mmc-pack.json und minecraft beziehungsweise .minecraft enthält. Prism kann den Instanzordner über das Kontextmenü öffnen; nicht nur den darin liegenden Spielordner wählen.
  4. Erfolgsmeldung abwarten. Das Programm sichert instance.cfg.before-customization und stellt den Pre-Launch-Befehl um. Danach wie gewohnt starten; am Schutzfenster erkennst du den neuen Weg.

Welten, eigene Mods und Optionen werden bei der Migration nicht verändert. Bei unbekannten eigenen Startbefehlen oder beschädigtem Zustand hält sie an. Sichere den Fehlerbericht; lösche weder packwiz.json noch .cozy. Ohne diese einmalige Umstellung aktiviert sich der Schutz nicht selbst.
